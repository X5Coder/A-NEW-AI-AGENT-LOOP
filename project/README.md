# X5Agent

---

## Setup

**Linux / Mac**

```bash
git clone https://github.com/X5Coder/A-NEW-AI-AGENT-LOOP.git
cd A-NEW-AI-AGENT-LOOP/project
pip install -e .
python main.py
```

**Windows**

```powershell
git clone https://github.com/X5Coder/A-NEW-AI-AGENT-LOOP.git
Set-Location A-NEW-AI-AGENT-LOOP/project
pip install -e .
python main.py
```
